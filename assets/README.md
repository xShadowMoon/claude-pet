# 素材放这里

仓库里不带角色素材：原作者那边的素材有版权，不能重新打包发布（来源见上一层的 `CREDITS.md`）。

把你自己的 GIF 放进这个文件夹，文件名对上下面这九个就能直接用：

| 文件名 | 用在哪 |
| --- | --- |
| `01_dizzy.gif` | 被拎着、摔了、报错、额度见底、整理记忆 |
| `02_smug.gif` | 完成一轮、被摸头 |
| `03_happy.gif` | 干活、跑命令、打招呼、挥手、欢呼 |
| `04_smile.gif` | 打盹、查资料、休息、告别 |
| `05_surprised.gif` | 等你确认、额度提醒 |
| `06_idle.gif` | 待机 |
| `07_shy.gif` | 思考、看代码、带小弟 |
| `08_walk_right.gif` | 向右走（本身朝右，不会再镜像） |
| `09_walk_left.gif` | 向左走（本身朝左，不会再镜像） |

建议用透明背景的 GIF，尺寸差不多就行，桌宠会按菜单里的大小缩放。想换文件名或者加新动作，改 `petapp/states.py` 里的 `STATES`。
