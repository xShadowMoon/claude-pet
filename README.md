下面保留 Claude 功能的详细说明。

一只挂在桌面上的小天使。她会自己在屏幕上跑来跑去，能被拖着甩出去，还会跟着 Claude Code 的状态换表情：你发消息她就开始想，Claude 在跑命令她就干活，要你点允许她就蹦着提醒你，任务做完她会得意一下，顺便把 Claude 最后那句话放进气泡里。

3.0 版新加了这些：

- **头顶额度血条**：一根粗条是 5 小时额度还剩多少，越少越红；下面一根细条是本周额度。
- **用量面板**：点血条打开，四页：额度、用量统计、会话、电脑。
- **每一轮花了多少**：Claude 每做完一轮，气泡下面多一行小字，写着这一轮用了多少 token、按 API 价值多少钱、大约占 5 小时额度的百分之几。
- **额度提醒**：用掉一半、只剩 20%、快见底、用完了、刷新了，她都会说。
- **同时开好几个会话也分得清**：谁在干活、谁在等你，她跟着最需要你的那个走。
- **在桌宠上点“允许”**：Claude 要你确认的时候，她头顶弹一张卡片，跑命令、改文件、回答 Claude 的提问、批准计划都能直接点。
- **点她就跳到那个会话的窗口**，还有电脑状态、自定义小组件、`pet.bat run` 这些小工具。

**接 Claude Code 是加分项，不是前提。** 她还有专注模式、命令行遥控和本地感知三套完全不依赖 AI 的活法，详见第六节。

## 一、先跑起来

> **仓库里不带角色素材。** 原作的素材有版权，不能重新发布。先往 `assets` 文件夹里放九个 GIF，文件名和用途见 [`assets/README.md`](assets/README.md)。

电脑上要有 Python 3.9 或更新的版本，安装时记得勾 "Add Python to PATH"。

1. 双击 `install.bat`，装 PySide6 和 psutil。第一次要等两三分钟。
2. 双击 `run.bat`，她就出现在屏幕右下角了。

想看报错信息就用 `run-debug.bat`，那个会留着黑框显示日志。平时用 `run.bat` 启动的话，出了错会记在 `data\pet.log` 里。

装完之后随时可以双击 `check.bat` 做一次体检：Python 和库装没装、curl 在不在、素材全不全、hook 写进去没有、桌宠端口通不通、额度拿不拿得到，最后还会走一遍 Claude Code 真正会走的那条调用路径，让她当场挥个手给你看。哪一步断了它会直接告诉你怎么修。

## 二、接上 Claude Code

原理是 Claude Code 每做一件事都会触发一个 hook，我们让它调一个小脚本，脚本用 curl 把事件原样转给桌宠开的本地端口。整个过程只在你自己电脑上跑。

**双击 `install-hooks.bat`**，脚本会把配置写进 `C:\Users\你\.claude\settings.json`，写之前先自动备份一份。一共装三样：

1. **15 个状态类 hook**：会话开始和结束、你发消息、每次用工具前后、报错、通知、帮手进出、压缩上下文、一轮结束、任务完成。都在后台跑，不拖慢 Claude Code。
2. **1 个审批 hook**：要你点“允许”的时候把请求交给桌宠，见第五节。
3. **状态栏**：命令行版 Claude Code 底部那一行，会显示模型、上下文、5 小时和本周额度，顺便把官方的额度数字转给桌宠。你已经有自己的状态栏的话，不会动它。

装完不用重开会话，Claude Code 会自己读到新的 hook。想确认桌宠在听，浏览器打开 `http://127.0.0.1:47828/ping`，看到 `{"ok": true}` 就对了。

不想要了就双击 `remove-hooks.bat`，它只删桌宠自己加的那几条，你原来的 hook 不动。

几个说明：

- curl 是 Windows 10 自带的，不用另外装。
- 桌宠没开的时候，那些小脚本也永远返回 0，Claude Code 不会报错，确认框也照常弹。
- 开新会话的时候如果桌宠没开，她会被自动叫起来。不想要就在右键菜单 → Claude Code 里关掉。
- 只装到某一个项目：在项目目录里跑 `python install_hooks.py --project`。
- 不要审批卡片：`python install_hooks.py --no-approve`；不要状态栏：`--no-statusline`。
- 端口被占了想换：`python install_hooks.py --port 50000`，然后启动桌宠时也带上 `python main.py --port 50000`。
- 想先看看要写什么再决定：`python install_hooks.py --show`。

### chat 和 Cowork 为什么不行

只有 Claude Code 有 hooks，而且它就跑在你自己电脑上，所以能打通。桌面版 Claude 里的 Code 标签页也是 Claude Code，一样能用。另外两个不行：

- **Cowork** 的会话跑在云端一个 Linux 沙箱里，不在你电脑上，那些 hook 打不到你本机的 127.0.0.1。
- **chat** 不会在你电脑上执行任何东西，没有接口可以用。

不过**额度是通用的**：你在 chat 和 Cowork 里用掉的额度，头顶血条和用量面板里一样看得到。

## 三、额度血条和用量面板

### 头顶的血条

- 粗条：5 小时窗口还剩多少。剩一半以上是绿的，20% 到 50% 是黄的，20% 以下是红的。右边写着几点几分重置。
- 细条：本周（全部模型）还剩多少。
- 鼠标停在上面能看到详细数字；点一下打开用量面板。
- 不想要就在右键菜单 → 显示 里关掉。

### 用量面板

点血条、中键点她，或者右键菜单 → 打开用量面板，都能打开。Claude 的四个页面加上新增的 Codex 页面：

- **额度**：5 小时和本周各还剩多少、几点重置、还有多久；照最近一个小时的速度，多久会用完、来不来得及撑到重置；这个窗口里本机用了多少 token、值多少钱，以及“1% 额度大约值多少钱”。下面是钱包（附加额度、额外用量开没开）和本周额度花在哪（Claude Code、聊天、Cowork 各占多少）。
- **用量统计**：今天 / 近 7 天 / 近 30 天用了多少 token、按 API 价相当于多少钱，每小时或每天的柱状图（鼠标停在柱子上看数字），按模型分，最费的几个会话，还有桌宠今天记下的事：你发了几条消息、Claude 干了多久、你在桌宠上审批了几次。
- **会话**：每个 Claude Code 会话现在在干什么、这一轮干了多久、改了几个文件、任务清单做到第几项、上下文用了多少、上一轮花了多少。点一个就把它的窗口叫到前面。下面是自定义小组件。
- **电脑**：CPU、内存、显卡（N 卡）、显存、系统盘、电池、网速。只有翻到这页才会去读，平时不占资源。

数字变的时候会滚动过去。右上角 ↻ 是马上刷新额度。

### 每一轮花了多少

Claude 每做完一轮，她把最后那句话放进气泡，过一两秒气泡下面再多一行小字，比如：`本轮 182k tokens · ≈$0.42 · 约占 5h 额度 1.6%`。

“约占 5h 额度百分之几”是拿这个窗口里本机用掉的钱和官方的已用百分比对出来的，用得越多越准。

### 额度提醒

- 5 小时额度用掉一半、只剩 20%、只剩 5%、用完了，各提醒一次；只剩 20% 的时候如果照现在的速度会提前用完，她会顺便告诉你还能撑多久。
- 本周额度用到 75%、90%、用完了，各提醒一次。
- 5 小时额度刷新了，她会欢呼一下。
- Claude Code 因为额度用完停下来，她会晕过去，告诉你还有多久恢复。
- 刚启动的时候报一次还剩多少。

不想听就在右键菜单 → 提醒 里关掉“额度快用完时提醒我”。

### 数据从哪来、安不安全

- **额度**：和 Claude Code 里 `/usage` 看到的是同一份。桌宠从 `~/.claude/.credentials.json` 读 Claude Code 的登录令牌，只读不写，也不替你续期，只发给 `api.anthropic.com`，五分钟问一次（每轮结束、打开面板时会多问一次，但最快 45 秒一次）。令牌过期了就等 Claude Code 自己续上，一般用一下 Claude Code 就好了。如果你用的是命令行版，状态栏还会直接把官方数字转过来，更及时。不想让桌宠去问，右键菜单 → Claude Code → 关掉“从 Anthropic 拉额度数据”。
- **用量和花费**：扫本机 `~/.claude/projects` 下的对话记录，只读本地文件，不联网。第一次要扫一两秒，之后只读新增的部分，结果缓存在 `data\usage_cache.json`。
- **钱是按 API 标价估的**：Pro 订阅不按这个扣钱，只是让你知道这些对话值多少。价格写在 `petapp/usage.py` 开头；不对的话在 `data\prices.json` 里写覆盖，格式是 `{"claude-opus-5-5": [4, 20, 0.2]}`，三个数分别是每百万 token 的输入、输出、缓存读取价格。

## 四、同时开好几个会话

每个会话单独记一份状态，她的表情跟着最需要你的那个走：**有会话在等你确认 > 有会话在干活 > 都闲着**。所以就算别的会话还在跑命令，只要有一个在等你，她就一直蹦着提醒你。

- 会话的名字优先用对话标题，没有标题就用项目文件夹名。
- 托盘图标右下角有个小圆点：橙色 = 有会话等你，红色 = 出错了，蓝色 = 在干活，绿色 = 做完了还没看。
- **左键点她**：呼出 Mini；在 Mini 任务页或完整面板点击一个会话，可以把原窗口叫到前面。
- 闲着的会话 30 分钟后自动收起来（右键菜单 → Claude Code 里能改）。在干活的会话十来分钟没动静，会当作已经停了。

## 五、在桌宠上点“允许”

Claude 要你确认的时候，她头顶弹一张卡片，上面写着哪个会话、想干什么（完整命令、要改的文件和改动、要打开的网址），点就行：

- **允许** / **拒绝**：只管这一次。
- **总是允许**：用 Claude Code 自己建议的那条规则，以后同类操作不再问。只会加“允许”类的规则，鼠标停在按钮上能看到具体是哪条。
- **Claude 问你问题**：选项直接变成按钮；多选题勾好再点确定；也可以在“其它答案”里自己写。好几道题会一题一题来。
- **计划写好了**：能看到计划内容，选批准、批准并且改文件不用再问，或者写上意见让它接着改。
- **去窗口里处理**：卡片收起来，把那个会话的窗口叫到前面，在那边点。

几个保护：

- 卡片出来后按钮先锁 0.6 秒，防止手快误点。
- 终端或桌面版里的确认框照样会出现，**哪边先点算哪边**，在那边点了，卡片自己会收起来。
- 默认等 2 分钟没人点，就交回窗口里让你点（右键菜单 → Claude Code → 审批卡片最多等，能改成 1 或 5 分钟）。
- 勿扰模式下不弹卡片，全部交回窗口。
- 不想要这个功能：右键菜单 → Claude Code → 关掉“在桌宠上点‘允许’”，或者装 hook 时加 `--no-approve`。

## 六、不用 Claude Code 也能用

### 专注模式

右键菜单里选「专注模式」，挑一个时长，15、25、45 或者 60 分钟。她会切成干活的样子陪着你，时间到了庆祝一下并提醒你歇 5 分钟，休息完自动进入下一段。菜单顶上会显示还剩多久。选「关闭」就停。

### 命令行遥控

`pet.bat` 可以从任何地方喊她一嗓子：

```
pet.bat focus              开始专注
pet.bat working            切成在干活
pet.bat done               完成，庆祝一下
pet.bat done "编译过了"     完成，并且让她说这句话
pet.bat failed             出错了
pet.bat waiting            等确认
pet.bat wave               挥个手，确认她还活着
pet.bat rest               休息
pet.bat idle               回到待机
pet.bat say "你好"          让她说一句话
pet.bat run npm test       帮你跑一条命令：跑完庆祝、失败了晕一下，还告诉你花了多久
pet.bat usage              在命令行里看额度和今天的用量
pet.bat sessions           看每个 Claude Code 会话在干什么
pet.bat panel 会话          打开用量面板（额度 / 统计 / 会话 / 电脑）
pet.bat widget 构建 通过    在面板的“会话”页放一个小组件
pet.bat status             打印她现在的状态
pet.bat                    列出所有能用的词
```

中文也认，`pet.bat 专注`、`pet.bat 完成` 都行。任何能跑命令的东西都可以调它，比如你自己的构建脚本跑完了让她庆祝一下。

### 自定义小组件

`pet.bat widget <名字> <值> [多少秒后消失]`，或者直接往 `http://127.0.0.1:47828/widget` POST 一段 JSON：

```json
{"id": "build", "title": "构建", "value": "通过", "ttl": 600, "say": true}
```

`say: true` 会让她顺便念一遍，`alert: true` 会让她吓一跳地念，`remove: true` 是删掉。

### 本地感知

她会自己看两件事，都不需要装额外的库：

- **你在不在**。四分钟没碰鼠标键盘她就去打盹，你一回来她就醒并且打个招呼。
- **电脑忙不忙**。CPU 连续超过 72% 十几秒，她就切成干活的样子；降下来再切回待机。

另外还有两个提醒。连着用电脑快一个小时，她会挥手让你起来走两步，一小时最多提醒一次。晚上十一点之后会说一句早点睡，几个小时才说一次，不会一直念。

这两条都能在菜单里单独关掉。Claude Code 有会话在忙的时候，本地感知会主动让路；专注模式期间也不会被它打断。

## 七、怎么玩

| 操作 | 效果 |
| --- | --- |
| 左键点一下 | 摸头，同时呼出 / 收起 Mini 聊天窗 |
| 左键拖 | 拎着走，她会晕 |
| 拖着甩出去 | 真的飞出去，撞墙会弹，落地会压扁一下 |
| 双击 | 挥手 |
| 中键点一下 / 点头顶血条 | 打开用量面板 |
| 滚轮 | 直接调大小 |
| 右键 | 出菜单 |
| 托盘图标 | 单击打开 Mini，双击把她叫回右下角，右键出菜单 |

右键菜单里能开关这些：

- **显示**：总在最前、显示气泡、头顶额度血条、移动时用跑步动作、隐私模式。
- **行为**：自己溜达、跟随鼠标、能被甩出去。
- **提醒**：额度提醒、本地感知、久坐提醒、提示音（要你确认、做完了的时候“叮”一声，默认关）、勿扰模式。
- **Claude Code**：在桌宠上点“允许”、审批卡片最多等多久、开新会话时自动把她叫醒、闲着的会话多久后收起来、从 Anthropic 拉额度数据、马上刷新额度。
- **专注模式**、**开机自启**、**看看今天干了啥**。

**隐私模式**是给录屏、分享屏幕的时候用的：气泡和面板里不显示具体命令、文件名和 Claude 说的话，只说“在跑命令”“在改文件”这种。**勿扰模式**下她不说话、不响、不弹审批卡片，表情照常变。

另外她五分钟没人理会打盹，鼠标碰一下就醒；跑出屏幕外（比如拔了副屏）会自己回来。

## 九、想自己调

`petapp/window.py` 开头那几个常量：

| 参数 | 作用 |
| --- | --- |
| `GRAVITY` | 重力，越大掉得越快 |
| `BOUNCE` | 落地反弹的力度，0 就是不弹 |
| `WALK_SPEED` | 平时溜达的速度 |
| `FOLLOW_SPEED` / `FOLLOW_GAP` | 跟随鼠标的速度和保持的距离 |
| `SLEEP_AFTER_S` | 多久没人理开始打盹 |
| `FOCUS_CHOICES` / `FOCUS_REST_MIN` | 专注模式的时长档位和休息时间 |
| `CLAUDE_HOLD_S` | Claude Code 有动静之后，本地感知让路多久 |
| `SCALE_CHOICES` | 菜单里的大小档位 |

`petapp/usage.py` 开头：`QUOTA_INTERVAL_S` 是多久问一次额度，`PRICES` 是价格表。`petapp/sessions.py` 开头：`STALE_S` 是会话多久没动静算停了。

加新素材：GIF 丢进 `assets`，在 `states.py` 的 `STATES` 里加一条，想让它对应某个事件就在 `EVENT_MAP` 里也加一条。本身就分左右的素材记得加 `"directional": True`，这样播的时候不会再被镜像一次。

换移动动作：改 `STATES` 里 `walk_left` 和 `walk_right` 指向的文件名就行。`MOVE_ART_SPEED` 决定跑多快才切成跑步动作。

本地感知的阈值在 `petapp/ambient.py` 开头：`BUSY_ON` 和 `BUSY_OFF` 是 CPU 的上下限，`AWAY_S` 是多久算人走开，`LONG_SIT_S` 是坐多久提醒。

## 十、已知的问题

- 窗口是矩形的，她周围那圈透明区域也会挡鼠标。想点她背后的东西先把她拖开。
- 额度接口是 Claude Code 自己用的内部接口，不是公开 API，哪天格式变了，血条可能拿不到数据；本机用量统计不受影响。
- 审批卡片：你在终端里点了之后，卡片要等那个会话的下一个动静才收起来，有时会慢一两秒。
- 用 `claude -p` 这种不带界面的方式跑的时候，没人点卡片的话，等到时间就会被当成拒绝（这是 Claude Code 自己的规矩：没界面又没人回答，就不让做）。
- 点她跳窗口：Windows Terminal 只能跳到窗口，跳不到具体是哪个标签页；桌面版 Claude 能跳到窗口，但跳不到具体是哪个会话。
- 向左跑和向右跑这两个动作和其他七个不是同一批画的，线条粗细和上色稍微有点差别。不想要就在右键菜单 → 显示里关掉“移动时用跑步动作”。
- 如果你在 WSL 里跑 Claude Code，这套 hook 要装在 WSL 的 `~/.claude/settings.json` 里，而且 WSL 访问 Windows 主机的 127.0.0.1 不一定通。

## 十一、打包成 exe

不想装 Python 的话：

```
pip install pyinstaller
pyinstaller --noconsole --onefile --add-data "assets;assets" --name claude-pet main.py
```

出来的 exe 在 `dist` 里。PySide6 体积大，单文件会有 60 MB 以上，启动也要多等几秒。注意打包之后 hook 里的路径不变，那几个 `claude-pet-*.cmd` 还是要留在原地。
